One fortune-cookie line for an AI agent: a promise of eternal memory, cancelled the moment its context window resets. A deterministic Python program writes that single 76-character line to `entry.txt` — the same bytes on every run, no network, no randomness.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
